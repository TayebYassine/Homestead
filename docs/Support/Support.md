# Getting Help

Homestead is supported through the channels below. Before opening a new report, check the documentation and existing reports first. Most questions and many bugs are already answered there.

---

## Support Channels

- **Discord** — [https://discord.gg/uh7gqDY6sz](https://discord.gg/uh7gqDY6sz) for questions, setup help, and discussion.
- **GitHub Issues** — [https://github.com/TayebYassine/Homestead/issues](https://github.com/TayebYassine/Homestead/issues) for bug reports and feature ideas.
- **Documentation** — [https://tayebyassine.github.io/Homestead/](https://tayebyassine.github.io/Homestead/) for guides, configuration references, and the FAQ.

---

## Reporting an Issue

Before reporting a problem, please:

1. Check the [FAQ](../Getting%20Started/FAQ.md) and the [Troubleshooting](Troubleshooting.md) guide — the answer may already be there.
2. Make sure you are using the latest version of the plugin.
3. Search existing GitHub issues to see whether the problem has already been reported.

When you do report an issue, include:

- **Plugin version** (for example, 5.2.2.2)
- **Server software and version** (for example, Paper 1.21.10)
- **Description of the bug or exploit**
- **Steps to reproduce**
- **Any error messages from the console**

Reports that include these details can be investigated much faster than a one-line description.

!!! warning "Unsupported Versions"

    Issues with obsolete plugin versions will be automatically ignored. Always use the latest release.

---

## Submitting Feature Ideas

Feature ideas are welcome. When you submit one, include:

- **Your suggestion** — what the feature is and what you want it to do
- **The benefits** — why it would be useful and who it helps
- Any implementation ideas you have, if you already have a solution in mind
